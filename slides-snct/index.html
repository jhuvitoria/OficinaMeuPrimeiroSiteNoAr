TELA 6 DE 8 ·

Suba no GitHub e ative o GitHub Pages

1. github.com → New repository → "meu-site"
   (visibilidade: Public, senão o Pages não funciona)
2. Add file → Upload files → arraste o CONTEÚDO da pasta
   (index.html, css, img...), não a pasta em si
3. Commit changes
4. Settings → Pages → Branch: main → Save
5. Aguarde 1–2 min e abra o link gerado

Amarelo = atenção neste ponto.

Checkpoint: o index.html aparece direto na raiz do repositório.

TELA 7 DE 8 ·

Gere o QR Code e poste no Mural

1. Copie a URL: https://usuario.github.io/meu-site/
2. Gere o QR Code em um gerador online
3. Teste lendo com o seu celular
4. Poste o QR Code + link no Mural do Curso 1

Amarelo = o que você troca.

Checkpoint: o site abriu no celular com o seu conteúdo.
